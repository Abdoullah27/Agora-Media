# منصة أجورا للنمو الرقمي - دليل المطور والهيكلة البرمجية

مرحباً بك في المستودع المصدري الخاص بمنصة **Agora Growth Engine**. هذا المستند هو "المرجع المركزي الأساسي" للمطورين الحاليين، والمبرمجين المستقبليين، ومساعدي الذكاء الاصطناعي (AI) المكلفين بتطوير أو صيانة هذا المشروع.

## 🚀 نظرة عامة على المشروع
تم بناء هذه المنصة لوكالة "أجورا ميديا"، وتهدف إلى تحويل الموقع التعريفي الساكن إلى منصة حية، ديناميكية، وعالية التحويل.
تدعم المنصة نظام معرض أعمال ضخم (يغطي السوشيال ميديا، الموشن جرافيك، الويب، الـ 3D، والهوية التجارية)، وتهدف لجذب العملاء بواجهة مستخدم زجاجية مبهرة، مع وجود لوحة تحكم متكاملة مخصصة لفريق العمل غير التقني للإدارة المستمرة.

**التقنيات المستخدمة (Tech Stack):** React 18, Vite, TypeScript, TailwindCSS, Framer Motion, react-router-dom, react-i18next.

## 🗺 هيكلية الروابط والتصفح (Routing)
يعمل التطبيق بنظام الصفحة الواحدة (SPA)، مع الاعتماد على التحميل المتأخر (Lazy Loading) للمسارات لتوفير أقصى سرعة أداء.

### الروابط الأساسية:
- `/` - **الصفحة الرئيسية:** تحتوي على الـ Banner، شريط عملاء الوكالة، الإحصائيات (KPIs)، أقسام الخدمات وآلية العمل، دراسات الحالة التحويلية، آراء العملاء، ونموذج المراسلة.
- `/portfolio` - **معرض الأعمال:** واجهة عرض ديناميكية تحتوي على تصنيفات فلترة لحظية.
- `/admin` - **تسجيل الدخول:** بوابة العبور الآمنة للمديرين.
- `/admin/dashboard` - **لوحة التحكم (CMS):** الواجهة الرئيسية لرفع المشاريع، تغيير النصوص، وتغيير الصور.

## ⚙️ الأنظمة التقنية الأساسية

### 1. نظام إدارة المحتوى الداخلي (Admin CMS)
نظراً لأن المشروع حالياً لا يملك خادم خلفي (No Backend)، فقد تم هندسته ليعمل بشكل كامل وحقيقي من خلال المتصفح:
- **إدارة الحالة (State):** برمجت من خلال الـ Context API بملف `CMSContext.tsx`.
- **قاعدة البيانات المؤقتة:** نظام الـ `localStorage` في المتصفح.
- **نظام رفع الصور:** يتعامل مكون `<ImageUpload />` مع واجهة السحب والإفلات، يحد المساحة بـ 1.5 ميجابايت لمنع الأعطال، ويحول الصورة المرفوعة لبيانات مشفرة `Base64` ليتم عرضها وتخزينها فورياً.
- **هيكلة البيانات:** محمية بصرامة عبر واجهات TypeScript داخل `src/types/cms.ts`.

### 2. الترجمة (التعريب) واتجاه الواجهة 
- يعتمد الموقع بالكامل على مكتبة `react-i18next` المتصلة بملفات `en.json` و `ar.json` الموجودة بداخل مجلد `src/locales/`.
- **قاعدة برمجية صارمة:** يُمنع تماماً كتابة نصوص ثابتة (Hardcoded) داخل ملفات الـ `tsx`، جميع النصوص يجب استدعاؤها عبر دالة `t()`.
- تتكيف جميع خواص التنسيقات (المسافات، حدود الطي، تحريك الأسهم) للعمل من اليمين لليسار (RTL) تلقائياً عند تغيير اللغة عبر بادئات الـ `rtl:` الخاصة بـ Tailwind.

### 3. إرشادات التصميم والنمط المظلم الداكن
- **خلفية مظلمة بالكامل:** لا يوجد هنا اللون الرمادي الفاتح. نعتمد السواد التام `hsl(0, 0%, 0%)`.
- **اللمسة الزجاجية النيون:** يعتمد المشروع بكثافة على أدوات `.glass-card` و `.glass-button`.
- **المؤشر التفاعلي المغناطيسي (Magnetic Cursor):** يتحول تلقائياً من نقطة مضيئة إلى حلقة شفافة متسعة حول الأزرار ليعطي إحساساً استثنائياً وفخماً.
- **زر الواتساب العائم:** مُشفر ليكون مرئياً في كافة صفحات التطبيق `App.tsx` بطابع داكن وشفاف لتجنب تشتيت العين باللون الأخضر الفاقع المعتاد.

### 4. الأداء ومحركات البحث (SEO)
- **الرسوميات الموفرة للطاقة:** المكونات الكثيفة مثل `ParticleGrid` تستخدم `useInView` لتوقيف حلقات التحريك (FPS) فوراً عند النزول للأسفل، لحفظ بطارية الموبايل.
- **Lazy Loading:** مسارات الإدارة والمعرض غير مدمجة في تحميل الصفحة الرئيسية.
- **البيانات الوصفية:** معتمدة على `react-helmet-async` لكل صفحة على حدة.

## 🏗 التطوير المستقبلي وقاعدة البيانات (Next Step)
عند نقل الموقع لإنتاج فعلي واسع، يُنصح بشدة بربطه بـ **Supabase** أو **Firebase**:
1. اتجه لـ `CMSContext.tsx`.
2. استبدل دالة `saveItems` لتصبح دالة استدعاء لـ API الخاص بـ Postgres.
3. بداخل `ImageUpload.tsx`، عدل نظام الـ Base64 ليرفع الملفات مباشرة إلى سحابة (Storage Bucket) ويرد برابط CDN.
*لن يحتاج فريقك لتغيير أي شيء في واجهة لوحة التحكم بفضل هذا الفصل الهيكلي الممتاز!*

## 🤖 إرشادات وتوجيهات لعملاء الذكاء الاصطناعي (AI Instructions)
أيها المساعد الذكي، إذا كُلفت بتحديث أو صيانة هذا المشروع، التزم بالآتي 100%:
1. **احمي الاستقرار المعماري:** اقرأ ملفات الـ `types` وجذر الـ `App.tsx` قبل استنتاج أي حل.
2. **احترم طابع Glassmorphism:** لا تُفسد التناسق بإضافة خلفيات بيضاء أو رمادية، التزم بالقيم الأصلية `var(--background)`, `var(--accent)`.
3. **لا تكسر الترجمة:** إذا أضفت ميزة جديدة، ابدأ أولاً بإضافة الكلمات لملفات الـ JSON، ثم اربطها.
4. **تطوير الـ CMS بحذر:** إذا أُمرت بإضافة قسم جديد (مثلاً "المدونات")، تأكد من تحديث `types/cms.ts`، وقوائم لوحة تحكم الأدمن، وفلترات العرض في نفس الوقت حتى لا ينهار النظام المؤقت `localStorage`.
5. **كود خفيف:** استعن بمميزات Tailwind الأساسية وتجنب حقن حزم `npm` ضخمة دون تفكير جاد.
6. **اشرح قبل أن تعبث:** لخّص دائماً الملفات التي ستقوم بتعديلها والفرضيات التي استندت إليها قبل البدء بالكتابة لتسهيل العودة في حال حدوث أخطاء.
